# Data-Analytics-Task
# Task 2 – Exploratory Data Analysis

## 📌 Objective

Perform Exploratory Data Analysis (EDA) on the cleaned dataset from Task 1 using Python.

The objective is to calculate important statistics, identify trends, patterns, and anomalies, create visualizations, and generate useful insights.

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## 📂 Dataset

The cleaned dataset from Task 1 was used for this analysis.

The dataset contains customer information such as:

- Customer ID
- Name
- Gender
- Age
- City
- Salary
- Join Date

## 🔍 Analysis Performed

The following analysis was performed:

1. Dataset overview
2. Descriptive statistics
3. Gender distribution
4. City-wise customer analysis
5. Age distribution
6. Salary analysis
7. Joining trend analysis
8. Outlier/anomaly detection
9. Age vs Salary relationship
10. Key insights identification

## 📊 Visualizations

The analysis includes:

- Customers by City
- Customer Distribution by Gender
- Age Distribution
- Salary Distribution
- Salary Outlier Analysis
- Age vs Salary
- Customer Joining Trend

## 💡 Key Insights

1. Identified the distribution of customers across different cities.
2. Analyzed the gender distribution of customers.
3. Examined the age distribution and identified unusual age values.
4. Compared salary patterns across different categories.
5. Analyzed the relationship between age and salary.
6. Identified potential anomalies in the dataset.
